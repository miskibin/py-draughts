# TurboEngine v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a v4 `turbo_weights.bin` + eval upgrades (tapered mg/eg, learned king PST, tall patterns) that beats the shipped v3 in a fair benchmark, per `docs/superpowers/specs/2026-07-12-turbo-v4-design.md`.

**Architecture:** All learned/hand leaf terms become packed `(mg, eg)` ints accumulated in one pass and blended by a men-count phase; king PST tables are filled from trained values; 6 new "tall" 2×4 men patterns are added next to the 11 horizontal ones. The trainer moves to a sparse COO feature representation so king counts and per-feature phase multipliers work. Search is untouched.

**Tech Stack:** pure-Python engine (stdlib only at runtime), numpy-only offline trainer, Scan 3.1 via HubEngine for labels, `draughts.Benchmark` for the gate.

## Global Constraints

- Engine runtime imports: stdlib only (`os`, `struct`, `time`). No numpy in `draughts/engines/turbo.py`.
- Weights file < 1 MB. (16 patterns × 6561 × 2 × int16 + king PST ≈ 0.42 MB ✓)
- Leaf speed gate: nodes/s regression vs v3 ≤ 20 %.
- Ship gate: benchmark Elo of v4 over v3 ≥ 2 × standard error, ≥ 200 games @ 0.1 s + ≥ 100 games @ 0.3 s.
- Training resources: workers ≤ 8, peak RAM < 6 GB, caches on `D:`.
- Commits: conventional style, no AI attribution (user preference).
- Branch: `engine/turbo-v4`.

## Key shared constants (defined in Task 2, used everywhere)

```python
# turbo.py
PACK_SHIFT = 32
PACK_K     = 1 << 15          # per-entry offset so packed fields stay non-negative
PHASE_MAX  = 40               # total men at game start

def pack(mg: int, eg: int) -> int:
    return ((mg + PACK_K) << PACK_SHIFT) | (eg + PACK_K)
```

Unpacking an accumulator of exactly `n` packed adds:

```python
eg_sum = (acc & 0xFFFFFFFF) - n * PACK_K
mg_sum = (acc >> PACK_SHIFT) - n * PACK_K
```

Black-side tables store **negated** values pre-packed (`pack(-mg, -eg)`) so the
hot loop only ever adds. `n` is a compile-time constant:
`N_PACKED = 36 + N_PATTERNS_ALL` (9 chunks × 4 tables + one packed add per pattern).

Phase blend (white-perspective, after unpack):

```python
men = (wm | 0).bit_count() + bm.bit_count()          # kings excluded
if men > PHASE_MAX: men = PHASE_MAX
score = (mg_sum * men + eg_sum * (PHASE_MAX - men)) // PHASE_MAX
```

Weight-vector layout (trainer + TPW2 file, one flat int16 array):

```
cols 0 .. N_PAT_ALL*6561*2 - 1 : men patterns, col = (p*6561 + idx)*2 + (0=mg | 1=eg)
KBASE = N_PAT_ALL*6561*2
cols KBASE .. KBASE+99         : white-king PST, col = KBASE + sq*2 + (0=mg | 1=eg)
```

Black king at square s uses the white table at square `49 - s`, negated.

```python
def _evaluate(wm, wk, bm, bk, white_to_move):
    acc = 0
    for c in range(9):
        sh = c * 7
        acc += (WM_T[c][(wm >> sh) & 127] + WK_T[c][(wk >> sh) & 127]
                + BM_T[c][(bm >> sh) & 127] + BK_T[c][(bk >> sh) & 127])
    if PAT_ACTIVE:
        for p in range(N_PATTERNS):
            s = _PAT_SH[p]; m = _PAT_WM[p]
            acc += PAT_W[p][_PAT_TW[p][(wm >> s) & m] + _PAT_TB[p][(bm >> s) & m]]
        n_packed = 36 + N_PATTERNS
    else:
        n_packed = 36
    eg = (acc & 0xFFFFFFFF) - n_packed * PACK_K
    mg = (acc >> PACK_SHIFT) - n_packed * PACK_K
    men = wm.bit_count() + bm.bit_count()
    if men > PHASE_MAX:
        men = PHASE_MAX
    score = (mg * men + eg * (PHASE_MAX - men)) // PHASE_MAX
    # mobility + skew stay plain ints, added after the blend (hand terms)
    empty = SQ_MASK ^ (wm | wk | bm | bk)
    score += MOBILITY_WEIGHT * (((wm >> 6) & empty).bit_count()
                                + ((wm >> 7) & empty).bit_count()
                                - ((bm << 6) & empty).bit_count()
                                - ((bm << 7) & empty).bit_count())
    w_all = wm | wk; b_all = bm | bk
    score -= SKEW_WEIGHT * abs((w_all & LEFT_MASK).bit_count()
                               - (w_all & RIGHT_MASK).bit_count())
    score += SKEW_WEIGHT * abs((b_all & LEFT_MASK).bit_count()
                               - (b_all & RIGHT_MASK).bit_count())
    return score if white_to_move else -score
```

Blend note: with mg == eg the `//` floor is exact (`(v*men + v*(40-men))//40 == v`), including negatives — no off-by-one.

Tall geometry (from design): strip `k` covers squares `{r*5+k, r*5+k+1}` for 4 consecutive rows `r0..r0+3`; set closed under 180° rotation:

```python
TALL_DEFS = ((1, 0), (1, 2), (5, 1), (5, 3), (3, 1), (3, 2))  # (r0, k)

def _tall_squares(r0: int, k: int) -> tuple[int, ...]:
    return tuple(sq for r in range(r0, r0 + 4) for sq in (r * 5 + k, r * 5 + k + 1))
```

Trit order = square order above (row-major, low row first). Chunk A = first 4 squares (rows r0, r0+1) with place values 3^0..3^3, chunk B = last 4 (rows r0+2, r0+3) with 3^4..3^7 baked into its tables. Index: `twA[(wm>>shA)&mA] + tbA[(bm>>shA)&mA] + twB[(wm>>shB)&mB] + tbB[(bm>>shB)&mB]`.

**Interfaces:**

TPW2 format (little-endian):

```
offset 0 : magic b"TPW2"
offset 4 : <H n_pat_h> <H n_pat_t> <H entries(=6561)> <H n_king(=50)>
offset 12: int16 men weights, (n_pat_h+n_pat_t) * entries * 2   (mg,eg interleaved)
then     : int16 king weights, n_king * 2                        (mg,eg interleaved)
```

Counts mismatch (patterns/entries != build) → all-zeros fallback, same as v3's contract.
